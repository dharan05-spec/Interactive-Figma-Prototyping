# Interactive Figma-style Prototype (HTML)

A clickable four-part prototype with slide transitions, an overlay menu, a bottom-sheet modal, toggle switches, and hover and press micro-interactions.

## Screens
1. Home: cards and a button to open settings
2. Detail: hero, description, and a booking button that opens the sheet
3. Settings: toggle switches and a save action
4. Overlay menu and bottom-sheet modal (shared across screens)

## Interactions
- On Click triggers: navigation cards, buttons, menu items
- Transitions: slide between screens (0.45 s, ease-out curve)
- Overlay menu: slides from the left with a dimmed backdrop
- Modal sheet: slides up from the bottom
- Micro-interactions: card lift on hover, button scale on press, toggle knob animation, toast confirmation

## Files
- `index.html`: open in a browser and click through
- `walkthrough.webm`: screen recording of the full flow
